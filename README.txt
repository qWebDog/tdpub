to Dublin — полный сайт для GitHub Pages

1. Распакуйте архив. Файл index.html должен лежать в корне репозитория,
   рядом с CSS/JS, изображениями и папками media, fonts, downloads.
   Не загружайте ZIP вместо распакованных файлов.
2. Загрузите все файлы с заменой текущих. Сохраните папки media и fonts,
   а также скрытый файл .nojekyll.
3. В GitHub откройте Settings → Pages → Deploy from a branch.
   Выберите ветку main и папку / (root), нажмите Save.
4. Дождитесь успешного завершения Pages build and deployment.
   Для репозитория qwebdog/tdpub адрес: https://qwebdog.github.io/tdpub/

Сборка, Node.js и npm не нужны. Видео включено в папку media.
В архиве новый рендер паба: красная дверь, чёрные оконные рамы,
коричневые шторы, золотые вывески. Четыре бочки сохранены.
Главный экран пересобран с новыми гостями и естественным освещением.
Каждый формат использует один общий исходный кадр для всех времён суток:
меняются только небо и свет, размер и положение объектов неизменны.

Заявки: Яндекс Форма ещё не подключена (enabled: false, formUrl пустой).
Сохраняется прежний сценарий Telegram. Инструкция: setup-leads.html.
Перед реальным сбором заявок заполните реквизиты в правовых документах
и завершите настройку формы. Токенов и паролей в архиве нет.

Превью ссылок подготовлено для https://qwebdog.github.io/tdpub/.
Если меняете адрес, обновите URL в метатегах index.html.
configure-seo.py и SEO.md приложены для последующего подключения своего
основного домена; запуск Python для обычного размещения не требуется.
