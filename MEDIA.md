# Медиа to Dublin

Главный экран и информационные блоки находятся в `dist/index.html`. Текст первого экрана не изменён.

## Сцены

- Утренний фон имеет обычные `src`/`srcset` и высокий приоритет. Это единственная немедленно запрашиваемая сцена.
- Остальные сцены используют `data-src`/`data-srcset`. `media-loader.js` подставляет мобильный источник до fallback `src`, ждёт загрузку/декодирование и объединяет повторные запросы.
- После загрузки страницы и в свободное время подготавливается только следующая сцена. Следующие фоны подгружаются по мере смены времени суток.
- Автосмена — 5 секунд, затухание — 0,75 секунды. При медленной загрузке остаётся текущая сцена. Последний ручной выбор имеет приоритет перед устаревшими запросами.
- Вне экрана и при открытой модалке анимация приостанавливается. `prefers-reduced-motion` отключает автосмену, ручной выбор остаётся доступен.

## Видео

`media/pub-atmosphere.mp4` указан в `data-src`, `preload="none"`; его постер — в `data-poster`. Начальная загрузка главного экрана не запускает запрос видео. При прокрутке на расстояние до 240 px от окна просмотра видео получает `src` и начинает загрузку. Автозапуск без звука выполняется при появлении в поле зрения; нативные элементы управления сохранены. За пределами видимой области воспроизведение приостанавливается.

Модалка «О нас» удалена: кнопка ведёт к `#overview`. Её старые скрипты и стили удалены. Исходный `media/about.mp4` сохранён как материал владельца; сайт его больше не загружает.

## Значки и превью

`social-preview.jpg` — полный существующий ночной кадр, только переведённый из WebP в JPEG, без изменения композиции. Браузер не загружает его как фон; его используют социальные сервисы для превью ссылки.

Favicon SVG/ICO/PNG и Apple Touch Icon используют золотую D из локального Rye. Пересоздание: `python scripts/build-brand-assets.py` (Pillow, fontTools, Brotli). Готовые файлы включены в сайт, на GitHub Pages никакая сборка не требуется. Manrope размещён локально; файл лицензии — `fonts/Manrope-OFL.txt`.
