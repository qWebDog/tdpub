На GitHub Pages админка не работает

Для входа по паролю, загрузки фотографий и сохранения цен нужен сервер с PHP 8.1 или новее. GitHub Pages выполняет только статическую часть сайта.

Как включить управление

Перенесите проект на российский PHP-хостинг с HTTPS, настройте приватный каталог и создайте пароль по инструкции. После переноса админка открывается по адресу /admin/index.php.
